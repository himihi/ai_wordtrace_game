# 逐字追踪（WordTrace）

一款基于「字级视觉线索 + 顺序路径」的微型益智微信小程序。

玩家根据目标成语的四个字，在散落的视觉节点（Emoji）中按字序依次点击正确节点，
四格填满即过关。

> 目标：30 关，验证核心玩法闭环。当前版本在 MVP 基础上加入了
> 背景音乐与音效、对局自动存档/继续游戏、放大节点图形等体验优化。

## 玩法简介

- 每关顶部有四个空位 `□ □ □ □`，对应一个四字成语。
- 屏幕中部散落 4~6 个视觉节点，节点上**不显示汉字**，只显示 Emoji 图形。
- 玩家按成语字序，依次点击正确的视觉节点。
  - 点对：节点弹跳变绿、填入空位、连线到上一节点，伴有「叮」音效。
  - 点错：节点抖动变红、低音提示，不加入路径。
- 四个正确节点按顺序点完即过关，撒花展示成语与释义，播放过关号角。
- 每关 3 次提示，提示会高亮下一个正确节点。
- 背景音乐循环播放，首页与游戏页均可一键开关（🎵 / 🔇），偏好本地保存。
- 对局进度（已选节点、填格、剩余提示）默认实时自动存档，游戏页 💾 按钮
  也可手动存档；中途退出后从首页「继续游戏」原样恢复，进入有存档的关卡
  时会弹窗让用户选择「继续游戏 / 重新开始」。

## 版本范围

### 已包含
- 30 个手工配置关卡，分 L1/L2/L3 三段递进
- 点击选点 + 即时判定（触感振动反馈）
- 视觉连线反馈（橙色虚线）
- 逐字填空展示
- 每关 3 次提示
- 通关撒花动画与成语释义
- 本地进度存储（`wx.Storage`）
- 关卡选择页（已通关打勾 / 未解锁锁定）
- 背景音乐循环 + 点对/点错/过关音效（可开关，默认开）
- 关卡内对局自动存档 + 💾 手动存档按钮，首页「继续游戏」恢复进度，
  进入有存档的关卡可弹窗选择继续或重新开始

### 暂不包含
- 拖拽连线、路径几何约束
- 倒计时、连击、排行榜
- 双成语并行、AI 实时生成、UGC 出题

## 技术栈

原生微信小程序 + TypeScript，无后端、无框架、无构建依赖（开发者工具原生编译 TS）。

## 快速开始

1. 用微信开发者工具导入本目录。
2. 项目为纯 TypeScript 源码（无 `.js` 文件），依赖 `project.config.json` 中的
   `"useCompilerPlugins": ["typescript"]` 由开发者工具自动编译；
   若模拟器报「未找到 pages/index/index.js」，请确认该字段存在并重新编译。
3. 若编辑器报类型错误，先在项目目录执行 `npm install`（安装 `miniprogram-api-typings`）。
4. 在 `project.config.json` 中把 `appid` 改成自己的 AppID（`touristappid` 为测试号）。
5. 编译运行：首页 → 开始游戏 / 继续游戏 / 关卡选择。

## 开发脚本

```bash
npm install          # 安装类型与校验依赖
npm run check        # TypeScript 全量类型检查
npm run validate     # 校验 30 关数据（结构/顺序/间距/边界）
npx tsx scripts/generate-audio.ts   # 重新合成音频资源（assets/audio/*.wav）
```

## 关卡配置指南

关卡数据在 `data/levels.ts`，单关结构：

```ts
{
  id: 1,
  idiom: '鹤立鸡群',
  explanation: '像鹤站在鸡群中一样……',
  correct: ['🦢', '🧍', '🐔', '👥'],  // 与 idiom 四字一一对应
  distractors: ['🦆']                  // 干扰项，L1 无 / L2 一个 / L3 两个
}
```

- 节点坐标**不要手写**：`utils/layout.ts` 按关卡 id 作为种子自动生成
  （L1 环形均匀分布，L2/L3 带最小间距约束的分散分布）。
- `correct` 数组顺序必须与 `idiom` 四字顺序一致（`npm run validate` 会强制校验）。
- 新增/修改关卡后务必运行 `npm run validate`。
- Emoji 优先选 iOS / Android 字形一致的常见字符；`emoji` 字段是视觉资源抽象层，
  后续可替换为图标字体或图片路径。

### 选题建议

优先选四字均为具体物象或动作的成语：

- 推荐：守株待兔、画蛇添足、对牛弹琴、掩耳盗铃、亡羊补牢、狐假虎威
- 慎选：井底之蛙（「之」难视觉化）、一鸣惊人（「一」抽象）
